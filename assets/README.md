# Identidade visual

Os banners do perfil possuem versões [clara](header-light.svg) e [escura](header-dark.svg).

O símbolo usado à esquerda substitui o antigo monograma M e repete a composição geométrica apresentada à direita: quadrado, arcos, círculos e linhas de construção. Os textos estão convertidos em curvas para manter a tipografia sem depender de fontes externas.

## Capa do LinkedIn

A capa correspondente foi ajustada para o formato de 1584 × 396 pixels. A edição da imagem foi feita com o recurso integrado imagegen, usando a capa original como alvo e o símbolo aprovado como referência. A exportação final preserva a proporção 4:1.
